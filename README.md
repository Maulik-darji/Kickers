# Kickers

Showcase website for Kickers: collectible die-cast sneakers. What die-cast cars did for cars, done for shoes.

Built with React + Vite. Design rules: flat colours only (no gradients) and square corners on every element.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Structure

- `src/App.jsx` — page sections (hero, collection, process, why, waitlist, FAQ)
- `src/components/Shoe.jsx` — the angular SVG sneaker used across the site
- `src/data.js` — Series 01 models, process steps, specs and FAQ copy
- `src/index.css` — all styles
